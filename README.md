# GenAI Data Assistant (RAG)

A Retrieval-Augmented Generation (RAG) system that enables natural language querying of private, custom datasets. Built using **LangChain**, **FAISS**, and **Flask**, this project leverages local LLMs (**Llama 3 via Ollama**) to ensure data privacy and zero-cost inference.

## 🚀 Overview

This project demonstrates a complete, end-to-end pipeline for an intelligent data assistant. It allows users to ask questions about a structured dataset (e.g., automotive sales figures) and receive accurate, context-aware answers generated by an LLM grounded in that specific data.

Unlike standard chatbots, this system:
1.  **Retrieves** precise facts from a local vector database (FAISS).
2.  **Augments** the prompt with this specific context.
3.  **Generates** an answer using a local LLM, ensuring no data leaves the local environment.

## 🛠️ Tech Stack

* **Orchestration:** [LangChain](https://python.langchain.com/) (LCEL)
* **API Framework:** [Flask](https://flask.palletsprojects.com/)
* **Vector Store:** [FAISS](https://github.com/facebookresearch/faiss) (Facebook AI Similarity Search)
* **LLM Serving:** [Ollama](https://ollama.com/) (Running Llama 3)
* **Embeddings:** HuggingFace (`all-MiniLM-L6-v2`)
* **Data Processing:** Pandas
